# Prompt Engineering 学习笔记

## 什么是 Prompt Engineering

Prompt Engineering（提示工程）是指设计和优化输入给大语言模型的提示词，
以获得更好输出的技术。它是有效使用 LLM 的关键技能。

## 常用技巧

### 1. Zero-shot Prompting（零样本提示）
直接向模型提问，不提供示例。
适用于简单任务。

### 2. Few-shot Prompting（少样本提示）
在提示中提供几个示例，引导模型理解任务模式。
示例数量通常为 3-5 个。
优点：无需微调模型即可适应新任务。

### 3. Chain-of-Thought（思维链）
要求模型展示推理过程，逐步思考。
对于数学、逻辑类问题特别有效。
触发词：让我们一步一步思考。

### 4. Role Prompting（角色提示）
让模型扮演特定角色，如专家、教师。
示例：你是一位资深 Python 工程师。

## 最佳实践

- 提示要具体明确，避免歧义
- 复杂任务拆解为子任务
- 指定输出格式（JSON、列表等）
- 迭代优化，测试不同表述
