# SPEC: 学术领域 GraphRAG 问答系统

## 1. 目标
构建一个基于"学术知识图谱 + 向量检索"的问答系统，能回答：
- 论文检索（"关于 LLM Agent 的综述论文有哪些"）
- 作者关系（"XX 和 YY 有合作关系吗"）
- 引用多跳（"哪篇论文引用了 XX？谁被引用最多"）
- 主题关联（"RAG 领域的研究热点有哪些"）

## 2. 范围
### 做
- 论文/作者/关键词/会议 实体知识库
- 引用/共著/发表 关系图谱（NetworkX，README 讲 Neo4j 生产方案）
- 图谱多跳检索 + 向量语义检索混合（GraphRAG）
- 多跳问答（需两步以上图遍历）
- Streamlit 演示界面 + 图谱可视化
- 100 条评测集 + 命中率报告

### 不做
- 全量论文库（数据量大）
- 论文推荐算法
- 多用户并发部署
- 严谨的引文数据库准确性（学术演示用）

## 3. 技术约束
- Python 3.11，复用 ai-agent-learning 的 llm_client/embedder
- 图谱：NetworkX（演示）；README 补 Neo4j
- 向量库：Chroma
- 界面：Streamlit
- 数据：公开学术数据（学术用途）

## 4. 验收标准
- [ ] 知识图谱 ≥ 100 个实体、200 条边
- [ ] 能回答 5 个多跳问题
- [ ] 100 条评测集命中率 ≥ 80%
- [ ] Streamlit 界面可交互 + 图谱可视化
- [ ] README 含架构图 + 部署说明 + 演示视频链接
