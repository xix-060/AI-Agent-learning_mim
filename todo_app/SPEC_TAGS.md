# SPEC: Todo 任务分类标签

## 1. 目标

给任务加分类标签（如"工作/学习/生活"），支持按标签筛选。

## 2. 范围

### 做

- 数据库加 tags 字段（逗号分隔字符串，不用新表）
- 添加/编辑任务时可设置标签
- 列表页按标签筛选（可多选）
- 统计条显示各标签数量

### 不做

- 标签颜色自定义
- 标签管理页（增删标签）
- 标签自动推荐

## 3. 技术约束

- 沿用现有 Flask + SQLite 结构
- 不引入新依赖
- 前端仍用原生 JS

## 4. 接口设计

- POST /api/todos：body 增加 tags 字段（可选，默认空串）
- PUT /api/todos/<id>：可更新 tags
- GET /api/todos?tag=工作：按单个标签筛选

## 5. 验收标准

- 添加带标签任务成功，DB 中 tags 字段正确
- 不传 tags 字段不报错（默认空）
- 按标签筛选只返回匹配任务
- 标签为空的任务在"全部"里显示
- 新增 pytest 覆盖：带标签创建、筛选、更新标签（至少 5 个用例）
- 现有测试不被破坏

## 6. 里程碑

M1：后端 API + 测试
M2：前端 UI
