# AI Agent 学习仓库

> 个人 AI Agent 入行学习记录

## 🚀 快速开始

```bash
# 1. 克隆仓库
git clone https://github.com/<user>/ai-agent-learning.git
cd ai-agent-learning

# 2. 配置环境
bash scripts/env.sh
conda activate ai-agent

# 3. 配置 API Key
cp .env.example .env
# 编辑 .env 填入你的 API Key

# 4. 运行
python hello_llm.py
```
