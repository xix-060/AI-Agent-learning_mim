# LLM 训练全流程

## 4 个阶段（从上到下，成本递减）

### 1. 预训练（Pre-training）

- 目标：从海量文本学习语言知识
- 数据：万亿级 token（网页/书籍/代码）
- 方法：预测下一个 token（自回归）
- 成本：百万到千万美元级（千卡集群）
- 产出：Base 模型（如 Qwen2.5-7B-Base）

### 2. 监督微调（SFT, Supervised Fine-Tuning）

- 目标：学会"听指令行事"
- 数据：指令-回答对（千到百万条）
- 方法：在指令数据上继续训练
- 成本：几百到几千美元（单卡到多卡）
- 产出：Instruct 模型（如 Qwen2.5-7B-Instruct）

### 3. 偏好对齐（RLHF / DPO）

- 目标：让回答符合人类偏好（有用/无害/诚实）
- 数据：偏好对（回答A优于回答B）
- 方法：
  - RLHF：训练奖励模型 + PPO 强化学习（复杂）
  - DPO：直接偏好优化（简单，2023年流行）
- 成本：中等
- 产出：对齐后的 Chat 模型

### 4. 参数高效微调（PEFT: LoRA/QLoRA）

- 目标：在特定任务上适配，不动全量参数
- 方法：只训练少量"附加参数"（LoRA）或量化后训练（QLoRA）
- 成本：极低（消费级显卡即可）
- 产出：任务专用模型

## 我们本周做什么？

| 阶段         | 是否做       | 原因   |
| :--------- | :-------- | :--- |
| 预训练        | ❌         | 成本太高 |
| SFT        | ✅ Day 2-3 | 核心技能 |
| DPO        | ✅ Day 5   | 了解原理 |
| LoRA/QLoRA | ✅ Day 2-4 | 重点实操 |

## 关键概念

- Base 模型 vs Instruct 模型 vs Chat 模型
- 全参数微调 vs 参数高效微调（PEFT）
- LoRA 是 PEFT 的一种，QLoRA = 量化 + LoRA
