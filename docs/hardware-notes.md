## 2. 选型三问

### Q1：模型多大？

显存需求 ≈ 参数量 × 精度字节数 × 1.2（激活等开销）

- 7B FP16 → \~17GB → 一张 4090（24GB）✅
- 14B FP16 → \~34GB → 两张 4090 或一张 A100 40G
- 72B FP16 → \~173GB → 4×A100 80G 或量化到 INT4（\~40GB）

### Q2：训练还是推理？

- 训练：显存 ×4（梯度+优化器状态），优先 H100/A100
- 推理：显存 ×1.2 即可，4090/L40S 很香

### Q3：并发多高？

- 低并发（<10 QPS）：单卡 + vLLM 足够
- 高并发：多卡张量并行 + 负载均衡

## 3. 网络（课纲：RoCE vs TCP/IP）

| 网络                                  | 带宽        | 延迟     | 用途        |
| :---------------------------------- | :-------- | :----- | :-------- |
| TCP/IP (以太网)                        | 10-25GbE  | \~ms 级 | 普通节点通信、存储 |
| RoCE (RDMA over Converged Ethernet) | 100-400Gb | \~μs 级 | 多卡训练参数同步  |
| InfiniBand                          | 200-400Gb | \~μs 级 | 大规模训练集群   |

#### 关键认知：多机训练瓶颈常在通信不在计算，所以要 RDMA/IB。
