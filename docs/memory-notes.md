# Agent 记忆（Memory）三层架构

## 1. 短期记忆（Short-term / Working Memory）

- 内容：当前对话的历史消息
- 存储：内存中的列表
- 特点：受上下文窗口限制（如 8K/32K/128K token）
- 策略：滑动窗口、摘要压缩
- 类比：人的"工作记忆"——你在对话中记得刚才说了什么

## 2. 长期记忆（Long-term Memory）

- 内容：历史对话、知识库、用户偏好
- 存储：向量数据库（Chroma/Milvus）
- 特点：容量无限，通过检索访问
- 策略：Embedding + 相似度检索
- 类比：人的"长期记忆"——你需要"回忆"才能想起

## 3. 情景记忆（Episodic Memory）

- 内容：过去的完整交互"情节"（不只是片段）
- 存储：结构化数据库 + 向量索引
- 特点：记录"什么时间、做了什么、结果如何"
- 策略：按时序组织 + 语义检索
- 类比：人的"情景记忆"——你记得"上周三和朋友去看了电影"

## Agent 记忆架构图

用户输入
↓
\[短期记忆] 当前对话历史（最近 N 轮）
↓
\[长期记忆] 检索相关历史（向量库 Top-K）
↓
\[情景记忆] 检索相关经历（"上次类似任务怎么做的"）
↓
拼接 → LLM → 回答
↓
更新三层记忆

## 为什么需要多层记忆？

- 只用短期记忆：超出窗口就忘了
- 只用长期记忆：每轮都要检索，慢且可能召回噪音
- 三层协同：短期保流畅，长期保知识，情景保经验
