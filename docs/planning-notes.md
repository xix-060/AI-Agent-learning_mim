# Agent 规划（Planning）4 种模式

## 1. CoT（Chain-of-Thought，思维链）

特点：线性推理，一步一步想。
适用：简单的多步推理（数学、逻辑）。
缺点：不能纠错，一步错步步错。
结构：A → B → C → 答案

## 2. ToT（Tree-of-Thoughts，思维树）

特点：树状搜索，每步生成多个分支，评估后选最优。
适用：需要探索多种可能性的任务（创意、博弈）。
缺点：成本高（LLM 调用次数多）。
结构：

```
        A
       / \
      B1  B2
     / \  / \
    C1 C2 C3 C4
    ↓
  最优路径
```

<br />

## 3. Plan-and-Execute（先规划后执行）

特点：先用 LLM 生成完整计划，再逐步执行。
适用：复杂任务需要全局规划（如"写一篇报告"）。
优点：比 ReAct 更有全局观。
缺点：计划可能不适应执行中的变化。
结构：Plan(步骤1,2,3...) → Execute(步骤1) → Execute(步骤2) → ...

## 4. Reflexion（反思）

特点：执行后反思结果，如果失败则改进重试。
适用：需要迭代优化的任务。
优点：能从失败中学习。
缺点：可能陷入循环。
结构：Act → Evaluate → Reflect → Act(改进) → ...

## 对比表

| 模式               | 结构  | 成本 | 纠错能力    | 适用场景  |
| :--------------- | :-- | :- | :------ | :---- |
| CoT              | 线性  | 低  | 无       | 简单推理  |
| ToT              | 树状  | 高  | 强（分支评估） | 探索性任务 |
| Plan-and-Execute | 两阶段 | 中  | 弱（计划固定） | 复杂任务  |
| Reflexion        | 循环  | 中  | 强（反思改进） | 迭代优化  |
