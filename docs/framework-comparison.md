# Agent 框架对比

| 维度      | 手写 ReAct | LangGraph | CrewAI | AutoGen |
| :------ | :------- | :-------- | :----- | :------ |
| 学习曲线    | 低（理解原理）  | 中         | 低      | 中       |
| 流程控制    | while 循环 | 状态机       | 顺序/层级  | 对话      |
| 人机协同    | ❌        | ✅         | ❌      | ✅       |
| 可暂停     | ❌        | ✅         | ❌      | ✅       |
| 多 Agent | ❌        | ✅         | ✅      | ✅       |
| 可视化     | ❌        | ✅ Mermaid | ❌      | ❌       |
| 适用      | 学习原理     | 生产级       | 快速原型   | 对话型     |

## 技术选型建议

- **学习阶段**：手写 ReAct（理解原理）
- **生产单 Agent**：LangGraph
- **快速多 Agent 原型**：CrewAI
- **对话型多 Agent**：AutoGen
- **项目 1 选择**：LangGraph（可控制流 + 可暂停 + 简历加分）
