# 数据蒸馏（Data Distillation）

## 1. 什么是蒸馏？

用强模型（如 GPT-4/DeepSeek）生成训练数据，
用来微调小模型。让小模型学到强模型的能力。

## 2. 为什么需要蒸馏？

- 人工标注成本高（$0.5-5/条）
- 强模型 API 便宜（$0.001-0.01/条）
- 可以快速生成大量高质量数据

## 3. 蒸馏流程

1. 设计种子 prompt（Seed Prompt）
2. 用强模型生成回答
3. 清洗/过滤低质量数据
4. 格式化为 SFT 数据
5. 微调小模型

## 4. 质量保障

- 多样性：prompt 表述要多样
- 正确性：抽查或用验证器
- 一致性：相同问题不同次生成要一致
- 长度控制：避免过长或过短

## 5. 注意事项

- 不要用竞品的模型蒸馏（合规风险）
- 生成数据要脱敏
- 数据质量 > 数量
