## 1. 哪种切块策略准确率最高？

**结论：固定大小切分（所有参数）和段落切分并列第一（100%）**

```
准确率排名：
100% ─ fixed-200, fixed-500, fixed-1000, paragraph
 80% ─ sentence-3, sentence-5
```

关键发现：
- 固定大小切分在 200~1000 字符范围内都保持 100% 准确率，稳定性最好
- 段落切分也达到 100%，但依赖文档有明确的段落结构
- 句子切分在两种参数下都只有 80%，丢失了部分上下文

## 2. 块太小（200字符）和块太大（1000字符）各有什么问题？

### 太小（200字符）

**问题：信息碎片化**

| 问题 | 说明 |
|------|------|
| 语义不完整 | 一个概念被切割到多个块，单块无法独立回答 |
| 块数过多 | 6个块 vs 3个块，增加存储和检索开销 |
| 丢失关联 | "Transformer" 和 "2017" 可能被分到不同块 |

```
示例：
[Chunk 1] "Transformer 是一种注意力机制模型，2017..."
[Chunk 2] "...年由 Google 提出，彻底改变了 NLP 领域..."
                  ↑
            如果只检索到 Chunk 2，就缺少了"Transformer"关键词
```

### 太大（1000字符）

**问题：噪声过多**

| 问题 | 说明 |
|------|------|
| 包含无关信息 | 一个块可能同时包含 Agent、MCP、Embedding 等多个主题 |
| 检索不精准 | 向量相似度计算时，无关内容稀释了核心语义 |
| Token 浪费 | 生成时需要截断，可能丢失真正相关的部分 |

```
示例：
[Chunk 1] "AI 发展史...Transformer...Agent...MCP...Embedding...(共1000字)"
                  ↑ 主题混杂，检索"Agent"时可能被 MCP 内容干扰
```

### 对比总结

| 维度 | 小块 (200) | 中块 (500) | 大块 (1000) |
|------|-----------|-----------|------------|
| 语义完整性 | ❌ 易断裂 | ✅ 平衡 | ✅ 完整 |
| 精准度 | ✅ 无噪声 | ✅ 适中 | ❌ 有噪声 |
| 块数量 | ❌ 多(6块) | ✅ 少(3块) | ✅ 最少(2块) |

## 3. 句子切分 vs 固定窗口，哪个更好？

**结论：固定窗口完胜**

| 对比项 | 固定窗口 | 句子切分 |
|--------|---------|---------|
| 准确率 | **100%** | 80% |
| 稳定性 | ✅ 200~1000都稳定 | ❌ 3句vs5句都不行 |
| 原理 | 强制切分 + overlap 保护 | 自然句断，但语义关联弱 |

**根本原因：句子边界 ≠ 语义边界**

```python
# 示例文本
text = "Transformer 是 Google 在 2017 年提出的模型。它基于自注意力机制。彻底改变了 NLP。"

# 句子切分（每3句）
chunk = "Transformer 是 Google 在 2017 年提出的模型。它基于自注意力机制。彻底改变了 NLP。"
# 看起来没问题？但如果文本是：

text2 = "AI 经历了三次浪潮。第一次是符号主义。第二次是连接主义。第三次是深度学习。"

# sentence-3（每3句）
chunk1 = "AI 经历了三次浪潮。第一次是符号主义。第二次是连接主义。"
chunk2 = "第三次是深度学习。"  # ← 太短，信息密度低

# 问题：问"第三次浪潮是什么"，可能检索到 chunk1 而不是 chunk2
```

**什么时候句子切分更好？**
- 文档本身就是短问答形式
- 每个句子都是独立的知识点（如 FAQ）

## 4. 我的推荐参数是什么？

### 🏆 首选：固定窗口 500 字符 + 50 字符 overlap

```python
CHUNK_SIZE = 500   # 单块 500 字符
OVERLAP = 50       # 10% 重叠
```

**理由：**
1. ✅ 准确率 100%（实验验证）
2. ✅ 块数适中（3块），不会过多或过少
3. ✅ 单块约 125~150 tokens，不超出 LLM 上下文窗口
4. ✅ 50字符 overlap 保证关键信息不会在块边界丢失

### 🥈 备选：固定窗口 300 字符 + 30 字符 overlap

```python
CHUNK_SIZE = 300
OVERLAP = 30
```

**适用场景：** 文档本身篇幅短、知识点分散在多个小标题下

### 🥉 特殊场景：段落切分

```python
# 只在文档结构特别清晰时使用
def by_paragraph(text):
    return [p.strip() for p in text.split('\n\n') if p.strip()]
```

**适用场景：** 博客文章、产品文档、教程（天然按段落组织内容）
