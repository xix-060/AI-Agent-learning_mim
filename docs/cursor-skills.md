# Cursor 五大核心功能

## 1. Tab 智能补全（最常用）

- 写代码时自动灰色预测，按 Tab 接受
- 技巧：先写注释描述意图，Tab 补全代码
- 示例：写 `# 计算两个日期之间的工作日数` 然后换行按 Tab

## 2. Cmd/Ctrl + K（行内编辑）

- 选中代码后按 Cmd+K，用自然语言改代码
- 示例：选中一个函数，输入"给这个函数加类型注解和 docstring"

## 3. Cmd/Ctrl + L（侧边栏对话）

- 对话模式，可以问代码、改代码、解释代码
- 关键：用 @ 引用精确上下文

## 4. Composer（多文件编辑）⭐

- Cmd+I 打开（新版叫 Agent 模式）
- 跨多个文件创建/修改代码
- 会自己创建文件、改 import、跑测试
- 这是"AI 写整个功能"的核心

## 5. @-references（上下文控制）

| 引用      | 作用                 | 示例                 |
| :------ | :----------------- | :----------------- |
| @file   | 引用单个文件             | @file src/agent.py |
| @folder | 引用整个目录             | @folder src/       |
| @code   | 引用具体函数/类           | @code ReActAgent   |
| @docs   | 引用官方文档             | @docs LangGraph    |
| @web    | 联网搜索               | @web vLLM 最新版本     |
| @git    | 引用 git diff/commit | @git 最近一次提交        |

## 黄金法则

1. 上下文越精准，AI 输出越好（用 @ 而不是复制粘贴）
2. 小步快跑：一次让它改一个函数，不要一次改十处
3. 永远 review AI 的代码，理解每一行
4. 让它写测试，测试通过才算完成
