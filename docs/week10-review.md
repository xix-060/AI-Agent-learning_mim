## 本周三大收获

1. **GraphRAG 的本质是"给 LLM 一条可验证的证据链"**——引用 2 跳扩展 + 关键词入边 2 跳，专治"短词匹配不上全名"的结构性盲区（ReAct 三个字母永远匹配不上论文全标题，不扩展引用链永远进不了证据）。
2. **严格 prompt 是性价比最高的优化**（单招 +12.3pp）：四条铁律让 LLM 逐字引用证据里的实体名/关系名，治好了"证据里有但回答改写掉"的半命中。
3. **评测集先去偏再优化**：数据驱动过滤（可达比例 <50% 删题）删掉 40 条图谱能力域外的过偏题——benchmark 不诚实，指标再好看也没意义。
